All synthetic assets are placeholders for development and require owner approval before public launch. No third-party stock licenses are attached to these files.

## 3D status

The final landing page does not use a 3D model, WebGL canvas, GLB, or GLTF asset. The fire-heart composition is a responsive image layer behind live HTML content, which keeps the reference look without sacrificing usability or device compatibility.
